### Dividing Decimals Using the Standard Algorithm

We can also use the standard algorithm to divide decimals by other decimals. The only difference is that we first need to find an equivalent division problem where the divisor is a whole number.

To illustrate, let's compute $1.11\div 0.3 \,.$ First, we write this division problem as a fraction:

$$

\dfrac{1.11}{0.3}

$$

Then, we multiply the numerator and denominator by $10$ so that we get a whole number in the denominator:

$$

\dfrac{1.11 \times 10}{0.3\times 10} = \dfrac{11.1}{3}

$$

Now we see that the division problem is equivalent to $11.1 \div 3.$ We can compute this using long division as usual:

From the long division, we find that $11.1 \div 3 = 3.7,$ so we conclude that

$$

1.11 \div 0.3 = 3.7 \, .

$$
