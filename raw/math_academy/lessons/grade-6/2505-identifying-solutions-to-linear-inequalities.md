### Introduction

We can find which values satisfy an inequality by substituting a number for the variable and checking whether the result is true.

For example, consider the following inequality

$$



y - 1 > 3



$$

Which of the following values of $y$ satisfies the inequality?

- $y=6$

- $y=8$

- $y=3$

Let's go through the possibilities one by one.

- Substituting the value ${\color{blue}y}={\color{blue}6}$ into the given inequality, we get: This is a *true* statement, so $y=6$ *satisfies* this inequality.

- Substituting the value ${\color{blue}y}={\color{blue}8}$ into the given inequality, we get: This is a *true* statement, so $y=8$ *satisfies* this inequality.

- Substituting the value ${\color{blue}y}={\color{blue}3}$ into the given inequality, we get: This is a *false* statement, so $y=3$ *does not satisfy* this inequality.

Therefore, the values that satisfy the inequality are $y = 6$ and $y = 8.$

### Example: Identifying Values Satisfying a Whole Number Inequality

#### Question

Which of the following values of $x$ satisfy the inequality $2x < 10\,?$

1. $x=0$

2. $x=2$

3. $x=5$

#### Explanation

Let's go through the possibilities one at a time.

- Substituting the value ${\color{blue}x}={\color{blue}0}$ into the given inequality, we get: This is a ** statement, so $x=0$ ** this inequality.

- Substituting the value ${\color{blue}x}={\color{blue}2}$ into the given inequality, we get: This is a ** statement, so $x=2$ ** this inequality.

- Substituting the value ${\color{blue}x}={\color{blue}5}$ into the given inequality, we get: This is a ** statement, so $x=5$ ** this inequality.

Therefore, only I and II satisfy the inequality.

### Example: Identifying Whole Number Inequalities Satisfied by a Value

#### Question

The value $a = 2$ satisfies which of the following inequalities?

1. $a + 2 > 5$

2. $2a < 6$

3. $3a - 1 < 10$

#### Explanation

Let's go through the possibilities one at a time.

- Substituting the value ${\color{blue}a} = {\color{blue}2}$ into the inequality I, we get: This is a ** statement, so $a = 2$ ** this inequality.

- Substituting the value ${\color{blue}a}={\color{blue}2}$ into the inequality II, we get: This is a ** statement, so $a = 2$ ** this inequality.

- Substituting the value ${\color{blue}a}={\color{blue}2}$ into the inequality III, we get: This is a ** statement, so $a = 2$ ** this inequality.

Therefore, the value $a=2$ only satisfies inequalities II and III.
