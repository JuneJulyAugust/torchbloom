## Lesson

### Introduction

A percentage change describes how a quantity increases or decreases relative to its original amount. In many situations, it is helpful to rewrite a percentage change as a multiplication of the original value. This makes it easier to compare quantities and combine multiple percentage changes.

Suppose a quantity has an original value of $x.$ A percentage change means adding or subtracting a fraction of this original amount.

For example, an increase of $20\%$ means adding $20\%$ of the original value.

First, write the percentage as a decimal:

$$



20\% = \dfrac{20}{100} = 0.20



$$

The increase is therefore

$$



0.20x.



$$

Hence, the new value is the original value plus the increase:

$$



x + 0.20x.



$$

Combining like terms gives

$$



x + 0.20x = (1 + 0.20)x = 1.20x.



$$

This shows that increasing a quantity by $20\%$ is equivalent to multiplying the original value by $1.20.$

Similarly, a percentage *decrease* subtracts a portion of the original value. For example, a $20\%$ decrease can be written as

$$



x - 0.20x = 0.80x.



$$

This means decreasing a quantity by $20\%$ is equivalent to multiplying the original value by $0.80.$

In general:

- A **percentage increase** results in a multiplier greater than $1.$

- A **percentage decrease** results in a multiplier less than $1.$

Rewriting percentage changes in this way helps us interpret how quantities are related and represent percentage changes using multiplication.

### Example: Expressing a Percentage Change as a Multiplication

#### Question

A gym reports that its membership decreased by $20\%$ over the past year. How can the current number of members be written as a multiplication of last year's membership?

#### Explanation

Let $x$ represent the number of members last year.

A decrease of $20\%$ means the membership decreases by $20\%$ of the original amount.

First write $20\%$ as a decimal:

$$



20\% = \dfrac{20}{100} = 0.20



$$

So, the amount of the decrease is

$$



0.20x.



$$

Hence, the current membership is the original amount minus the decrease:

$$



x - 0.20x



$$

Combining like terms, we get

$$



x - 0.20x = 0.80x.



$$

This shows that a $20\%$ decrease in membership is equivalent to multiplying last year's membership by $0.80.$

### Interpreting Multipliers as Percentage Change

We can express a percentage change as a multiplication of the original value. We can also work in the opposite direction: given a multiplication, we can interpret the percentage change it represents.

Suppose a quantity has an original value of $x.$

If the new value is written as

$$



1.18x,



$$

this means the new value is $1.18$ times the original value.

We can rewrite this expression as

$$



1.18x = (1 + 0.18)x = x + 0.18x.



$$

This shows the new value is the original value plus an additional $0.18x.$

Since

$$



0.18 = 18\%,



$$

this represents an *increase* of $18\%.$

Now consider a different expression:

$$



0.85x



$$

We can rewrite this as

$$



0.85x = (1 - 0.15)x = x - 0.15x.



$$

This shows the new value is the original value minus $0.15x.$

Since

$$



0.15 = 15\%,



$$

this represents a *decrease* of $15\%.$

In general, the difference between the multiplier and $1$ tells us the size of the percentage change.

### Example: Interpreting a Multiplication as a Percentage Change

#### Question

The current number of students enrolled at a school equals $1.25$ times the number of students enrolled last year. What does this change represent as a percentage increase?

#### Explanation

Let $x$ represent the number of students enrolled last year.

Multiplying last year's enrollment by $1.25$ means the current enrollment is

$$



1.25x.



$$

We can rewrite this expression as

$$



1.25x = x + 0.25x.



$$

This shows that the current enrollment is last year's enrollment, $x,$ plus an additional $0.25x.$

Since

$$



0.25 = \dfrac{25}{100} = 25\%,



$$

the enrollment increased by $25\%$ of last year's enrollment.

### Interpreting Successive Percentage Changes

Sometimes a quantity changes by a percentage more than once. When this happens, each percentage change is applied to the *new value*, not the original value.

Suppose a quantity has an original value of $x.$

If the quantity increases by $25\%,$ the new value is found by multiplying by $1.25$:

$$



1.25x.



$$

Now suppose the new value increases again by $8\%.$ This second increase applies to the *updated amount*, $1.25x.$

An $8\%$ increase corresponds to multiplying by $1.08,$ so the new value becomes

$$



1.08(1.25x).



$$

This expression shows that the original value is first multiplied by $1.25,$ and then the result is multiplied by $1.08.$

We can also multiply the factors:

$$



1.08 \times 1.25 = 1.35.



$$

So the final value can be written as

$$



1.35x.



$$

This means the final amount is $1.35$ times the original amount. This corresponds to an overall increase of $35\%.$ Notice that this is larger than simply adding the percentages together ($25\% + 8\% = 33\%$).

When interpreting successive percentage changes, each change applies to the *new value*, so we represent the changes by multiplying the corresponding factors.

### Example: Expressing Successive Percentage Changes as a Multiplication

#### Question

A concert hall increases the price of a ticket by $25\%.$ Later in the year, the new ticket price increases again by $8\%.$ How can the final ticket price be written as a multiplication of the original ticket price?

#### Explanation

Let $x$ represent the original ticket price.

An increase of $25\%$ means the ticket price is multiplied by

$$



1.25.



$$

So, after the first increase, the ticket price is

$$



1.25x.



$$

The new ticket price then increases again by $8\%.$ This means the new amount is multiplied by

$$



1.08.



$$

Since the second increase applies to the **, we multiply $1.25x$ by $1.08$:

$$



1.08(1.25x)



$$

Now multiply the factors:

$$



1.08 \times 1.25 = 1.35



$$

So, the final ticket price is

$$



1.35x.



$$

This shows that the final ticket price can be found by multiplying the original ticket price by $1.35.$

### Example: Interpreting Multiplications as Successive Percentage Changes

#### Question

A publishing company tracks the number of subscribers to its online magazine. The expression $1.12(0.80x)$ represents the number of subscribers after two changes, where $x$ is the original number of subscribers. What percentage changes does this expression represent?

#### Explanation

Let $x$ represent the original number of subscribers.

Multiplying $x$ by $0.80$ represents a decrease of $20\%.$

So after the first change, the number of subscribers becomes

$$



0.80x.



$$

The expression then multiplies this new amount by $1.12.$ Multiplying by $1.12$ represents an increase of $12\%.$

So the expression

$$



1.12(0.80x)



$$

means that the number of subscribers first decreases by $20\%,$ and then the new number of subscribers increases by $12\%.$
