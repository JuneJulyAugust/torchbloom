### Introduction

We can represent two-variable equations using tables. For example, consider the following equation:

$$



y = 5 + x



$$

Notice that:

- If $x=0,$ then $y=5 + 0 = 5.$

- If $x=1,$ then $y=5 + 1 = 6.$

- If $x=2,$ then $y=5 + 2 = 7.$

- If $x=3,$ then $y=5 + 3 = 8.$

### Example: Finding the Missing Constant in an Equation With Addition and Subtraction

#### Question

The equation that represents the relationship between $y$ and $x$ is $0$ What is the missing number?

#### Explanation

We notice that, for every $x$ value, we subtract $4$ to get the corresponding $y$ value.

Therefore, the equation is $y = x - {\color{blue}4}.$ So the missing number is $4.$

### Example: Finding the Missing Constant in an Equation With Multiplication and Division

#### Question

The equation that represents the relationship between $b$ and $a$ is $0$ Find the missing number.

#### Explanation

We notice that, for every $a$-value, we divide by $\color{blue}5$ to get the corresponding $b$-value.

Therefore, the equation is $b = \dfrac{a}{\color{blue}5}.$ So the missing number is $5.$

### Finding Missing Values in a Table Given the Independent Variable

Consider the table with missing values below that represents the equation

b = a + 5.

$$



b = 4 + 5 = {\color{blue}{9}}



$$

Let's add it to our table.

Next, let's find the second missing value.

### Finding Missing Values in a Table Given the Dependent Variable

To find the missing value of $a,$ we substitute $b = 7$ into the relationship $b = a + 5{:}$

$$



7 = a + 5



$$

Now, we solve this equation by subtracting $5$ from both sides:

$$



\begin{aligned}7 & =𝑎+5 \\ 7−5 & =𝑎+5−5 \\ 2 & =𝑎+0 \\ 2 & =𝑎\end{aligned}



$$

So, the second missing number is $2.$

### Example: Constructing a Table Given an Equation

#### Question

The table represents the equation $q = 4p.$ From ****, what are the missing numbers?

#### Explanation

To calculate the missing value of $q,$ we substitute $p=2$ into the relationship $q = 4p{:}$

$$



q = 4 \times 2 = {\color{blue}{8}}



$$

To find the second missing value, we substitute $q=20$ into the relationship $q = 4p{:}$

$$



20 = 4p



$$

Now, we solve this equation by dividing both sides by $4{:}$

$$



\begin{aligned}20 & =4𝑝 \\ \frac{20}{4} & =\frac{4𝑝}{4} \\ 5 & =\frac{4𝑝}{4} \\ 5 & =𝑝\end{aligned}



$$

So, from top to bottom, the missing numbers are $8$ and $5.$

### Example: Identifying an Equation Given a Table

#### Question

What equation represents the relationship between $z$ and $t?$

#### Explanation

Note that, for every $z$-value, we divide by $\color{blue}3$ to get the corresponding $t$-value.

Therefore, the equation is $t = \dfrac{z}{3}.$
