### Introduction

Recall that the *mode* of a data set is the value that occurs most often in a data set. In this lesson, we'll learn how to determine the mode of a data set presented as a frequency table.

Consider a data set with the corresponding frequency table shown below. What is the mode of this data set?

From the table, we see that the highest frequency is $7,$ corresponding to the value $8.$

Therefore, the mode of the data set is $8.$

Recall that some data sets have more than one mode. Let's see an example of how this looks when analyzing frequency tables.

### Example: Finding the Mode of a Data Set

#### Question

An IT support team recorded how many tickets individual technicians resolved during a shift. The results are shown in the following frequency table.

What are the mode(s) of this data set?

#### Explanation

The mode is the value with the highest frequency in the data set.

From the frequency table, we see that the highest frequency is $6,$ corresponding to resolving $4$ and $7$ tickets.

Therefore, the data set has two modes: $4$ and $7.$

### Example: Finding a Possible Missing Frequency

#### Question

A music club recorded the number of songs each student memorized over a month. The incomplete data set is shown below.

If the only mode of the data set is $2,$ which of the following values could be the value of $x?$

1. $7$

2. $8$

3. $6$

#### Explanation

The mode is the value with the greatest frequency.

We are told that $2$ is the only mode, so its frequency $x$ must be greater than the frequency of every other value in the table.

The largest known frequency is $7$ (for $4$ songs). So, we must have

$$



x > 7.



$$

Now, let's test each value:

- We cannot have $x=7$ since $7 > 7$ is false. $\color{red}{\times}$

- We can have $x=8$ since $8 > 7$ is true. $\color{green}{\checkmark}$

- We cannot have $x=6$ since $6 > 7$ is false. $\color{red}{\times}$

Therefore, the correct answer is option ****

### Example: Finding a Possible Missing Frequency With Bimodal Data

#### Question

A farmer recorded the number of apples picked from each tree. The incomplete data set is shown below.

If $3$ is a mode of the data set, which of the following values could be the value of $x?$

1. $7$

2. $8$

3. $6$

#### Explanation

The mode is the value with the greatest frequency.

We are told that $3$ is a mode of the data set, so its frequency $x$ must be at least as large as the greatest known frequency in the table.

From the table, the highest known frequency is $7$ (for $5$ apples). So, we must have

$$



x \geq 7.



$$

Now, let’s test each value:

- We can have $x=7$ since $7 \geq 7$ is true. $\color{green}{\checkmark}$

- We can have $x=8$ since $8 \geq 7$ is true. $\color{green}{\checkmark}$

- We cannot have $x=6$ since $6 \geq 7$ is false. $\color{red}{\times}$

Therefore, the correct answer is, "I and II only."
