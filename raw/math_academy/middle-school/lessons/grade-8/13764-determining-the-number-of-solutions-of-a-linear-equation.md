### Introduction

The **number of solutions** of an equation tells us how many values of the variable make the equation true.

For a linear equation in one variable, we simplify both sides first. If there are parentheses, we use the distributive property. Then, we collect like terms and compare what is left.

- If the equation reduces to a single value, such as it has exactly one solution.

- If the variable terms cancel and leave a true statement, it has infinitely many solutions.

- If the variable terms cancel and leave a false statement, it has no solution.

### Contradictions and No Solutions

A **contradiction** is a statement with no variables that is always false. In a linear equation, a contradiction means no value of the variable can make the original equation true.

The three patterns are:

- Different variable terms after simplifying usually lead to one value, so the equation has exactly one solution.

- Matching expressions on both sides lead to a true statement, so the equation has infinitely many solutions.

- Matching variable terms but different constants lead to a false statement, so the equation has no solution.
