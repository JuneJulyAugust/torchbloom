## Lesson

### Introduction

Yet another way to represent the center of a data set is to use the **mode** of the data. The mode is the value that occurs most often in the data set.

To demonstrate, let's compute the mode of the data set below:

$$

2, \: 3, \: 3, \: 1, \: 4

$$

Here, the number $3$ appears twice, while all the other numbers ($1,$ $2,$ and $4$) each appear only once.

Therefore, the mode is $3.$

**Note:** Sometimes, there may be multiple values that occur most often in a data set. For example, in the data set below, the numbers $1$ and $3$ each appear twice.

$$

2, \: 3, \: 3, \: 1, \: 1

$$

In these cases, there are multiple modes in the data set. Here, there are two modes: $1$ and $3.$

### Example: Computing the Single Mode of a Data Set

#### Question

What is the mode of the following data set?

$$

8, \; 12, \; 4, \; 12, \; 3, \; 12, \; 8, \; 4, \; 12, \; 8

$$

#### Explanation

Let's start by sorting our data set:

$$

3, \; 4, \; 4, \; 8, \; 8, \; 8, \; 12, \; 12, \; 12,\; 12

$$

The mode is the value that occurs the most often in the data set. We have that:

- $3$ appears $1$ time

- $4$ appears $2$ times

- $8$ appears $3$ times

- $\color{blue}12$ appears $\color{red}4$ times

The value $\color{blue}12$ appears more frequently than the others ($\color{red}4$ times in total).

Therefore, the mode is $12.$

### Example: Computing Multiple Modes of a Data Set

#### Question

Find the mode of the following data set:

$$

5, \: 4, \: 5, \: 4, \: 3, \: 4, \: 5, \: 9

$$

#### Explanation

Let's start by sorting our data set:

$$

3, \: 4, \: 4, \: 4, \: 5, \: 5, \: 5, \: 9

$$

The mode is the value that occurs the most often in the data set. We have that:

- $3$ appears $1$ time

- $\color{blue}4$ appears $\color{red}3$ times

- $\color{blue}5$ appears $\color{red}3$ times

- $9$ appears $1$ time

The values $\color{blue}4$ and $\color{blue}5$ both appear more frequently than the others ($\color{red}3$ times each in total).

Therefore, the data set has two modes: $4$ and $5.$

### Example: Word Problems

#### Question

A team scored the following number of goals in each of the six hockey games it played:

$$

2, \; 4, \; 3, \; 5, \; 3, \; 4

$$

Find out the mode of the team's goal distribution.

#### Explanation

Let's start by sorting our data set:

$$

2, \; 3, \; 3, \; 4, \; 4, \; 5

$$

The mode is the value that occurs the most often in the data set. We have that:

- $2$ appears $1$ time

- $\color{blue}3$ appears $\color{red}2$ times

- $\color{blue}4$ appears $\color{red}2$ times

- $5$ appears $1$ time

The values $\color{blue}3$ and $\color{blue}4$ both appear more frequently than the others (both $\color{red}2$ times in total).

Therefore, the data set has two modes: $3$ and $4.$
