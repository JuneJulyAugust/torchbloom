### Introduction

A **ratio** is a mathematical statement that expresses the relative sizes of two quantities.

As an example, let's look at the triangles and circles below.

![Instructional graphic](../../../lesson-assets/prealgebra/topic-534/670382e0375c46f2.png)

We can express the ratio of the number of circles to the number of triangles as follows:

$$

{\color{blue}{\textrm{number of circles}}} : {\color{red}{\textrm{number of triangles}}}

$$

To find this ratio, we start by counting the number of occurrences of each shape:

- First, we count the number of circles. There are $\color{blue}5$ circles.

- Next, we count the number of triangles. There are $\color{red}2$ triangles.

Therefore, the ratio of circles to triangles is ${\color{blue}5}:{\color{red}2}.$

We can describe this ratio in words as follows:

*The ratio of circles to triangles is ${\color{blue}5}:{\color{red}2}$ because there are ${\color{blue}5}$ circles*for every*${\color{red}{2}}$ triangles.*

### Example: Finding a Ratio

#### Question

What ratio describes the number of pentagons to the total number of shapes?

![Instructional graphic](../../../lesson-assets/prealgebra/topic-534/bfbbfa41a736c4e0.png)

#### Explanation

We can express the ratio of the number of pentagons to the total number of shapes as follows:

$$

\textrm{number of pentagons} : \textrm{total number of shapes}

$$

To find this ratio, we start by counting the number of occurrences of each shape:

- First, we count the number of pentagons. There are $3$ pentagons.

- Next, we count the total number of shapes. There are $6$ shapes.

Therefore, the ratio of pentagons to total shapes is $3:6.$

### Example: Word Problems

#### Question

A merchant has $8$ black crates and $5$ green crates. What ratio describes the number of green crates to the total number of crates?

#### Explanation

We can express the ratio of the number of green crates to the total number of crates as follows:

$$

\textrm{number of green crates} : \textrm{total number of crates}

$$

We compute our ratio as follows:

- First, we count the number of green crates. There are $5$ green crates.

- Next, we count the total number of crates. There are $8+5 = 13$ crates.

Therefore, the ratio of green crates to total crates is $5:13.$

### Example: Interpreting Ratios

#### Question

The ratio of red marbles to blue marbles in a bag is $7:8.$ What is the meaning of this ratio?

#### Explanation

If the ratio of red marbles to blue marbles is ${\color{red}{7}}:{\color{blue}{8}},$ it means that there are ${\color{red}{7}}$ red marbles for every ${\color{blue}{8}}$ blue marbles.
