### Introduction

We can find which values satisfy an inequality by trial and error, which involves substituting a number for the variable and checking to see if we get a true statement.

For example, which of the following values of $y$ satisfy the inequality $y - 1 > 3\,?$

1. $y=6$

2. $y=2$

3. $y=3$

Let's go through the possibilities one at a time.

- Substituting the value ${\color{blue}y}={\color{blue}6}$ into the given equation, we get: This is a **true** statement, so $y=6$ **satisfies** this inequality.

- Substituting the value ${\color{blue}y}={\color{blue}2}$ into the given equation, we get: This is a **false** statement, so $y=2$ **does not satisfy** this inequality.

- Substituting the value ${\color{blue}y}={\color{blue}3}$ into the given equation, we get: This is a **false** statement, so $y=3$ **does not satisfy** this inequality.

Therefore, only I satisfies the inequality.
