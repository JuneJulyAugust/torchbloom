### Introduction

A **set** is a collection of objects known as **elements** or **members**.

Usually, the elements of a set have some property in common. For example, a set could be a class at school where the students are the members of the set. The common property is that all the students are members of the class.

To write a set, we list the elements between two braces (curly brackets). Commas are used to separate the elements.

So, for example, the set of the primary colors would be written as

$$


S =\{ \text{yellow}, \: \text{red}, \: \text{blue} \}.


$$

The elements of this set are $\text{yellow},$ $\text{red},$ and $\text{blue}.$

A set that does not contain any elements is known as the **null set** or **empty set** and is written as either

$$


\emptyset \quad \text{or} \quad \{\}.


$$

Note the following:

- *A set may contain other sets as elements.* For instance, the set contains the set $\{5, 6\}$ as an element. However, it does *not* contain the elements $5$ and $6$.

- *Order doesn't matter.* The order in which the elements are listed is irrelevant. For instance, the following sets represent the same thing: It's usually easier to understand a set if the elements are listed in some order.

- *Duplicates don't matter.* Having multiple copies of an element does not affect the structure of a set. For example, the following sets represent the same thing: When writing a set, we should try to organize it so that each element is listed once only.

### Element Notation

By convention, sets are denoted by uppercase letters, while lowercase letters refer to elements of the set.

There is a special notation, $\in,$ for expressing elements of sets. For example, if $a$ is an element of a set $A,$ we write

$$


a \in A.


$$

For example, for the set $S,$ given by

$$


S = \{ \text{yellow}, \text{red}, \text{blue} \},


$$

we can write

$$


\text{yellow}\in S.


$$

Similarly, if $a$ is *not* an element of $A,$ then we write

$$


a \notin A.


$$

For example,

$$


\text{green} \notin S.


$$

### Example: Using Element Notation

#### Question

Write the following statement using element notation:

$\qquad$ $1$ and $2$ are elements of a set $S,$ but $3,$ $4,$ and $5$ are not.

#### Explanation

If $a$ is an element of $S,$ we write $a \in S.$ Otherwise, if $a$ is ** an element of $S,$ we write $a \notin S.$

- Since $1$ and $2$ are elements of $S,$ we write $1,2 \in S.$

- Since $3,$ $4,$ and $5$ are ** elements of $S,$ we write $3,4,5 \notin S.$

All together, we have the following statement:

$$


1,2 \in S\quad \textrm{and}\quad 3,4,5 \notin S


$$

### Ellipsis Notation

When a set contains only a few elements, we can write them all explicitly.

For example, the set $A$ containing all positive even integers less than $20$ could be written as follows:

$$


A = \{2, \: 4, \: 6, \: 8, \: 10, \: 12, \: 14, \: 16, \: 18\}


$$
